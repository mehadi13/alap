## 🔑 Default Roles & Access

- **Admin Role**: Full administrative access to `client-app` (`/clients`, `/consultations`, `/settings`).
- **Public User / Client Role**: Access to public solutions catalog, consultation submission, callback requests, and personal client portal views.
