# ALAP Client Manager (`client-app`)

A dedicated frontend application for managing ALAP's clients, consultation leads queue, and solution deployment contracts.

## Key Features
- **Client Directory & Portfolio**: Manage active, onboarding, and in-consultation client profiles.
- **Consultation Leads Queue**: Track and transition new inquiries submitted from ALAP web forms.
- **Backend Service Integration**: Configured to connect with the Spring Boot 3.4.3 backend service on `http://localhost:8080/api/v1`.
- **Design System & Theme**: Matches ALAP design tokens (`#5B5CE2`/`#7C7EF2` accents, dark/light theme switching, Tailwind CSS v4, Lucide icons).
- **English Interface**: Dedicated English admin & client management UI.

## Getting Started

Run the development server on port 3001:

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
